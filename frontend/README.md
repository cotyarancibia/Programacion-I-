# Frontend - Adopcion Mascotas (Vite + React)

Frontend inicial del proyecto de adopcion de mascotas.

## Desarrollo

```bash
cd frontend
npm install
npm run dev
```

La aplicacion debe levantar en `http://localhost:3000`. Vite esta configurado con `strictPort` para fallar si el puerto 3000 no esta disponible.

## Verificaciones

```bash
npm run lint
npm run build
```
